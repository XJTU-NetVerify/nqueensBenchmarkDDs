# Removed legacy implementations

The archived `NDD-SoA` project was removed from this checkout. Its source and
documentation remain available in Git history.

Use maintained `NDD` and `NDD-BCDD` in place of the former SoA variants.
The former `NDD-SoA-FD-ZDD` finite-domain experiment has no direct equivalent
in the maintained Boolean-bit ZDD label mode. These legacy targets are not
registered in the benchmark runner.
